Get started

Install the package, choose your outcome and treatment columns, and fit the estimator. The default uses lasso nuisance models, automatic calibration, and jackknife confidence intervals.

Install

Install
python -m pip install calibratedDML
remotes::install_github("Larsvanderlaan/calibratedDML")

Python requires version 3.10 or later. To install Python from the current GitHub source:

python -m pip install git+https://github.com/Larsvanderlaan/calibratedDML.git

Estimate a treatment effect

In Python, supply a covariate matrix X and treatment and outcome vectors A and y. In R, name the columns in your data frame.

Estimate a treatment effect
from calibrateddml import CalibratedDML

fit = CalibratedDML(
    control_level=0,
    outcome_model="lasso",
    treatment_model="lasso",
    random_state=123,
).fit(X, A, y)

fit.summary()
fit.confint()
library(calibratedDML)

fit <- calibrated_dml(
  data = df,
  outcome = "Y",
  treatment = "A",
  covariates = c("W1", "W2", "W3"),
  control_level = 0,
  outcome_model = "lasso",
  treatment_model = "lasso",
  seed = 123
)

summary(fit)
confint(fit)

The summary contains mean potential outcomes for each treatment arm and differences from control_level. Use confint() to extract confidence intervals.

Choose nuisance models

Set outcome_model and treatment_model to "lasso", "linear", or "random_forest". You can also use custom learners or supply predictions from models fitted elsewhere.
