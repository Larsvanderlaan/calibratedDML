R package

Use calibrated_dml() to fit from a data frame, or calibrated_dml_from_nuisances() to calibrate predictions from existing models.

Install from GitHub

remotes::install_github("Larsvanderlaan/calibratedDML")

Fit from a data frame

library(calibratedDML)

fit <- calibrated_dml(
  data = df,
  outcome = "Y",
  treatment = "A",
  covariates = c("W1", "W2", "W3"),
  control_level = 0,
  outcome_model = "lasso",
  treatment_model = "lasso",
  seed = 123
)

summary(fit)
confint(fit)

Name the outcome, treatment, and covariate columns, and specify control_level. The package cross-fits the nuisance models and returns arm means and treatment-versus-control contrasts.

Supply nuisance predictions

fit <- calibrated_dml_from_nuisances(
  A = A,
  Y = Y,
  mu_mat = mu_mat,
  pi_mat = pi_mat,
  treatment_levels = c(0, 1),
  control_level = 0
)
summary(fit)

Supply one row per observation and one column per treatment level in each matrix. mu_mat contains cross-fitted outcome means; pi_mat contains treatment probabilities. Use column names matching the treatment levels or set treatment_levels explicitly.

Choose nuisance learners

Built-in choices include lasso, linear models, random forests, GAMs, and boosted trees. You can also supply a custom model list, a SuperLearner library, or an sl3 learner. The custom-learner vignette gives examples.

Confidence intervals

The default is inference = "jackknife" with 100 groups. Use "bootstrap" for bootstrap intervals or "wald" for intervals based on estimated influence values. See the inference guide for when to use each method.
