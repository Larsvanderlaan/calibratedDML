R Package

Use the R package when you want doubly robust inference, not just doubly robust point estimates.

Use the R package when you want the standard calibrated DML workflow for categorical treatment effects, either with package-fitted nuisances or with your own cross-fitted nuisance inputs.

Install Main Entry Points

Why Use The R Package

Main function calibrated_dml() is the default route for routine work.
Bring your own nuisances calibrated_dml_from_nuisances() is built in.
Adaptive methods adaptive_calibrated_dml() is advanced and binary-treatment only.

Compact R Example

fit <- calibrated_dml(
  data = df,
  outcome = "Y",
  treatment = "A",
  covariates = c("W1", "W2", "W3"),
  control_level = 0,
  outcome_model = "lasso",
  treatment_model = "lasso",
  calibration_method = "auto",
  inference = "wald"
)

summary(fit)

Entry Points

Main R entry points

Start with the standard estimator. Use the direct nuisance path when you already have cross-fitted nuisance estimates, and use the adaptive path only for the advanced binary-treatment case.

Standard

calibrated_dml()

  • Categorical treatment support in the standard estimator
  • Fits nuisances internally when mu_mat and pi_mat are omitted
  • Returns fitted objects with printed summaries
  • Supports wald, bootstrap, and jackknife

Direct Nuisance Path

calibrated_dml_from_nuisances()

  • Supply cross-fitted mu_mat and pi_mat directly
  • Useful for custom nuisance pipelines and reproducibility checks
  • Still runs the calibration, debiasing, and inference layers
  • Works with explicit treatment-level alignment

Backends

Nuisance backends

The R package includes built-in model options and can also work with sl3 or SuperLearner stacks.

Built-in choices

Standard built-in model names include options such as "mean", "lm", "lasso", "gam", "random_forest", "boosted_trees", and "auto".

sl3 integration

Advanced users can fit nuisances through the tlverse ecosystem when they want learner stacks or richer cross-validated pipelines.

SuperLearner integration

The package also leaves room for SuperLearner libraries when that is the preferred nuisance-estimation path.

Defaults

Practical defaults and inference choices

Most R users should start with calibrated_dml(), choose the inference mode explicitly, and treat the adaptive route as advanced.

Start here

Use calibrated_dml() first and use the package-managed nuisance path unless you already have cross-fitted nuisances.

Inference modes

The standard R interface supports "wald", "bootstrap", and "jackknife". Choose the uncertainty layer explicitly rather than inheriting it by accident.

Adaptive workflow

Use adaptive_calibrated_dml() only when you intentionally want the advanced binary-treatment route.

It is binary-treatment only, and inference can be less stable than standard calibrated DML.
