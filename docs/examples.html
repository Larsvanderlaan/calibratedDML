Workflows

Common workflows

Each card gives when to use it, what to call, and why it is the right route for inference.

Workflow 1

Standard estimator from raw data

Use this when your target is a mean potential outcome or treatment-vs-control contrast and you want the package to fit nuisances, cross-fit, calibrate, and run inference for you.

Why this workflow: It is the easiest route to calibrated, doubly robust inference from raw data.

Python

CalibratedDML(...).fit(X, A, y)

R

calibrated_dml(data, outcome, treatment, covariates, ...)

Workflow 2

Estimator from supplied nuisance matrices

Use this when you already have cross-fitted nuisance functions and want the package to handle only calibration, debiasing, and inference.

Why this workflow: It lets you keep your nuisance pipeline and use the package for calibrated inference.

Python

CalibratedDML(...).fit_from_nuisances(A, y, mu_mat, pi_mat, ...)

R

calibrated_dml_from_nuisances(A, Y, mu_mat, pi_mat, ...)

Workflow 3

Multi-arm treatment with control contrasts

Use the standard estimator when treatment has more than two levels and your estimand is every arm mean plus each treatment-vs-control contrast. The package aligns columns to treatment levels and reports results relative to the chosen control arm.

Why this workflow: It gives the same calibrated inference idea for multi-arm means and control contrasts.

Python

CalibratedDML(control_level=0, ...)

R

calibrated_dml(..., control_level = 0)

Practical Notes

Two practical things to check

If you already have nuisance estimates, they should usually be cross-fitted. If you later branch to adaptive methods, inference choice matters more.

Supplied nuisances

When you use the direct nuisance path, the expected input is a set of cross-fitted nuisance estimates rather than in-sample fits.

Inference choice

Standard calibrated DML is the routine default. If you branch to adaptive binary-treatment methods, be deliberate about whether you want Wald, bootstrap, or jackknife intervals.
