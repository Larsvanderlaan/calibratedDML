Examples

Use raw data to fit the full estimator, or supply cross-fitted nuisance predictions from your own models. Both R and Python return arm means, treatment contrasts, and confidence intervals.

Fit from raw data

The getting-started example generates data, fits the estimator, and shows the output in both languages. The package cross-fits outcome and treatment models, then calibrates the pooled predictions.

Supply nuisance predictions

Use fit_from_nuisances() in Python or calibrated_dml_from_nuisances() in R when you already have cross-fitted predictions. Both matrices have one row per observation and one column per treatment level.

InputColumn for treatment level a
mu_matPredicted conditional mean E[Y | A = a, W].
pi_matPredicted treatment probability P(A = a | W).
Calibrate supplied predictions
fit = CalibratedDML(control_level=0).fit_from_nuisances(
    A=A,
    y=y,
    mu_mat=mu_mat,
    pi_mat=pi_mat,
    treatment_levels=[0, 1],
)
fit.summary()
fit <- calibrated_dml_from_nuisances(
  A = A,
  Y = Y,
  mu_mat = mu_mat,
  pi_mat = pi_mat,
  treatment_levels = c(0, 1),
  control_level = 0
)
summary(fit)

Align the columns with treatment_levels. Keep observations in the same row order in the outcome, treatment, and nuisance arrays.

Compare more than two treatments

The standard estimator accepts categorical treatments. Set control_level to choose the comparison arm; the summary reports each arm's mean potential outcome and its contrast with that control. For supplied predictions, include a column for every treatment level.

Choose your learners

Python accepts scikit-learn regressors and classifiers. Treatment classifiers must implement predict_proba(). For example:

from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor

fit = CalibratedDML(
    outcome_model=RandomForestRegressor(n_estimators=200, random_state=123),
    treatment_model=RandomForestClassifier(n_estimators=200, random_state=123),
    random_state=123,
).fit(X, A, y)

R accepts built-in model names, custom model lists, and optional SuperLearner and sl3 learners. See the custom-learner vignette for examples.
