Adaptive DML

Adaptive DML uses a reduced summary of the effect problem, then debiases using that summary.

Adaptive DML is for binary treatment. It tries to replace a hard, fully unrestricted effect-estimation problem with a lower-dimensional summary of the part that matters for the target, then performs debiasing on top of that summary. When the true effect structure is simpler than a fully unrestricted model, this can make estimation noticeably more stable.

What It Does Modes Overview

What It Does

Adaptive DML reduces the effect problem before it debiases

The main idea is simple: instead of treating the whole effect problem as fully unrestricted, adaptive DML first builds a reduced summary of the part most relevant for the target and then performs debiasing with that reduced summary in place. For users, the key takeaway is that the method is trying to simplify the estimation problem without changing the substantive target at the truth.

Dimension Reduction

Why scalar summaries and reduced models show up

The method tries to summarize the part of the data that matters for the target using something lower-dimensional than the full covariate vector. This is not arbitrary variable dropping. It is a way of concentrating on the part of the effect problem that most directly drives bias correction and efficiency.

Scalar outcome-regression score

One option is a calibrated outcome-regression score: a one-dimensional summary built from the estimated outcome model.

Scalar estimated CATE

Another option is a scalar estimated CATE, where the treatment effect is summarized through a single learned effect score.

Learned low-dimensional representation

More generally, the method can use a learned low-dimensional representation when that representation captures the part of the data most relevant for the target.

CATE Story

For the ATE, adaptive DML often focuses on the CATE

The ATE is the average treatment effect, and the CATE is the treatment effect as it varies across covariate values. In many adaptive DML setups, the central question is whether that CATE can be represented well by something simpler than a fully unrestricted function.

Nearly Constant Effects

If the CATE is close to constant

A simple CATE model can help a lot. When treatment effects are nearly homogeneous, the adaptive estimator can gain substantial stability by not paying for unnecessary flexibility.

Heterogeneous Effects

If the CATE varies

The method does not require exact homogeneity. It can still adapt by fitting a richer CATE summary when the data support more heterogeneity.

Guarantees In Practice

What the guarantees mean in practice

Super-efficient means lower variance at favorable truths because the estimator is able to exploit a simpler pattern in the true treatment effects. It does not mean uniformly better, and it comes with a more delicate inference story.

Adaptive DML

Can be more efficient when the effect structure is simple

If the truth follows a simpler pattern, adaptive DML can have lower variance and lower mean-squared error than a more uniformly regular estimator. The tradeoff is that inference depends more on the learned reduced structure.

Standard Calibrated DML

Broader regularity and doubly robust inference guarantees

Standard calibrated DML is built around broader regularity and a doubly robust inference story for the original target, rather than trying to gain efficiency from a simpler pattern in the treatment effects.

Usual causal assumptions still matter

Adaptive DML still depends on the usual causal conditions behind outcome-regression and treatment-effect estimation, including consistency, no unmeasured confounding, and overlap.

Adaptive gains need a good reduced summary

The method works best when its reduced summary captures the important pattern in the true treatment effects well enough to simplify the problem without distorting it.

Weak overlap may be helped, zero overlap is not solved

Adaptive structure can improve stability when overlap is weak, but it does not remove the underlying population-level support requirements needed for causal interpretation.

Package Modes

Current package entry points

The package currently exposes adaptive binary-treatment methods through separate Python and R interfaces. Adaptive methods use isotonic calibration internally, but the key distinction between the modes is what gets summarized and calibrated.

Mode

plugin

Calibrates the outcome regression and plugs that calibrated prediction into the target.

Mode

calibrated_rlearner

Fits and calibrates a CATE summary. This is useful when effect heterogeneity may be limited but not absent.
