Adaptive DML

Adaptive DML estimates the binary-treatment ATE using a learned treatment-effect model. It can reduce variance when treatment effects have a simpler structure than the full outcome regression, particularly with limited treatment overlap.

Model treatment-effect heterogeneity

The calibrated_rlearner mode estimates the conditional average treatment effect (CATE), calibrates it with isotonic regression, and estimates the ATE using the resulting one-dimensional summary. The baseline outcome regression and propensity score can still depend on all covariates.

Estimation

  1. Estimate the baseline outcome regression and propensity score with cross-fitting.
  2. Fit a preliminary CATE using an R-learner and calibrate its predictions with weighted isotonic regression.
  3. Average the calibrated treatment effects and estimate uncertainty using the fitted working model.

Why the overlap requirement changes

Let \(\pi(W)=\Pr(A=1\mid W)\) and \(\tau(W)=\mathbb{E}[Y(1)-Y(0)\mid W]\). In AIPW, the outcome residual is multiplied by \((A-\pi(W))/[\pi(W)\{1-\pi(W)\}]\). This multiplier can be large when treatment is nearly deterministic at a given \(W\).

For least-squares debiasing, restricting how the treatment effect varies changes the denominator. The three population expressions below describe an unrestricted effect, a constant effect, and an effect that depends on a summary \(S(W)\).

Treatment-effect modelDenominator of the residual multiplier
Unrestricted effect, as in AIPW\(\pi(W)\{1-\pi(W)\}\)
Constant treatment effect\(\mathbb{E}[\pi(W)\{1-\pi(W)\}]\)
Effect is a function of \(S(W)\)\(\mathbb{E}[\pi(W)\{1-\pi(W)\}\mid S(W)]\)

For the third model, treatment variation is averaged among covariate values with the same summary. Some of these covariate values may have little overlap, while others provide enough treatment variation to estimate their shared effect. Adaptive DML estimates this summary from the CATE; the oracle expression uses \(S(W)=\tau(W)\).

When to use it

Consider the calibrated R-learner when limited overlap makes AIPW imprecise and treatment effects may be nearly constant or well described by a learned summary. At distributions with such structure, adaptive estimators can have lower asymptotic variance than regular nonparametric ATE estimators. The paper develops inference through the corresponding oracle projection.

Fit an adaptive estimator

Adaptive binary-treatment ATE
from calibrateddml import AdaptiveCalibratedDML

fit = AdaptiveCalibratedDML(
    control_level=0,
    mode="calibrated_rlearner",
    random_state=123,
).fit(X, A, y)
fit.summary()
library(calibratedDML)

fit <- adaptive_calibrated_dml(
  data = df,
  outcome = "Y",
  treatment = "A",
  covariates = c("W1", "W2", "W3"),
  control_level = 0,
  mode = "calibrated_rlearner",
  seed = 123
)
summary(fit)

The adaptive methods are experimental and use isotonic calibration. The alternative mode="plugin" calibrates outcome-regression predictions and averages them to estimate arm means and the ATE.
