Adaptive Methods

Adaptive methods for the advanced binary-treatment workflow.

These methods target a different efficiency tradeoff than standard calibrated DML. They are for advanced binary-treatment analyses, not the default route for routine causal inference.

When To Use This

Use this only when you intentionally want the adaptive route

This page is for advanced users with binary treatment who want the adaptive or super-efficient route rather than the main calibrated DML workflow.

Binary treatment

The adaptive interface is for binary-treatment analyses rather than the multi-arm standard workflow.

Intentional choice

Use this only when you are deliberately choosing its different efficiency tradeoff, not as a general default.

Routine work

For routine calibrated doubly robust inference, go back to standard calibrated DML.

Tradeoffs

What changes relative to standard calibrated DML

Adaptive methods can improve point-estimation efficiency in favorable settings, but the uncertainty layer is harder and confidence intervals can be less stable.

Potential upside

More aggressive efficiency target

In settings that favor the adaptive estimator, point estimates can be more efficient than the standard calibrated DML route.

Main cost

Inference is more delicate

Interval construction needs more care, and uncertainty can be less stable than with standard calibrated DML.

Caveats

Practical caveats

Treat adaptive methods as a specialized follow-on rather than the package entry point.

Binary-treatment only

This page does not replace the standard multi-arm workflow.

Advanced use only

Inference choices such as Wald, bootstrap, and jackknife deserve extra care here.

Keep a baseline

Compare back to standard calibrated DML before treating the adaptive route as your default analysis.
