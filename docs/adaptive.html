Adaptive DML

Adaptive DML estimates the ATE through a calibrated treatment-effect summary.

The adaptive estimator documented here is for binary treatment. It learns a treatment-effect summary, calibrates that summary, and averages it to estimate the ATE.

Overview Estimator Overview
  • Binary treatment only
  • ATE estimated through a CATE summary
  • Narrower inference scope than standard calibrated DML

At A Glance

Scope Binary-treatment adaptive ATE estimation.
Modes calibrated_rlearner and plugin.
Calibration Adaptive methods calibrate the learned treatment-effect summary.

Scope

What is documented on this page?

This page documents adaptive DML for binary-treatment ATE estimation. The estimator works by learning and calibrating a treatment-effect summary rather than relying on a fully unrestricted outcome model.

Target

Average treatment effect

The target parameter on this page is the ATE, not a general collection of adaptive estimands.

Treatment

Binary treatment

The adaptive workflow documented here is for treatment versus control.

Working structure

Treatment effects may be simpler than the full outcome surface

This estimator is most appealing when the treatment-effect pattern is simpler than a fully unrestricted model would suggest.

Baseline

Standard calibrated DML remains the broader default

If the priority is broader inferential scope, standard calibrated DML remains the default baseline.

Estimator

How is the ATE estimated?

Adaptive DML first learns a treatment-effect summary, then calibrates that summary, and finally averages it to estimate the ATE.

Step 1

Estimate nuisance components

Estimate the outcome and treatment-assignment components needed for the adaptive estimator.

Step 2

Learn the treatment-effect summary

Learn the conditional treatment-effect pattern that will be used to construct the ATE.

Step 3

Calibrate the learned summary

Calibrate the treatment-effect summary before forming the final estimator.

Step 4

Average to the ATE

Average the calibrated treatment-effect summary to estimate the ATE.

Structure

Why go through a treatment-effect summary?

The adaptive estimator can be more stable when treatment effects are simpler than the full outcome surface.

Simple pattern

Near-constant effects

When treatment effects are close to constant, a simpler treatment-effect model can stabilize ATE estimation.

Heterogeneity

Effects may still vary

The estimator does not require exact homogeneity. Richer treatment-effect patterns can still be learned when supported by the data.

R-learner setup

Why the partially linear setup is used

The partially linear setup separates baseline outcome prediction from treatment-effect learning. That separation is what allows the estimator to work through a treatment-effect summary.

In practice, the method removes baseline outcome and treatment assignment patterns before learning the treatment-effect summary.

Inference

What is the tradeoff relative to standard calibrated DML?

Adaptive DML can be more stable when the treatment-effect pattern is simple. Its inferential scope is narrower and more delicate than standard calibrated DML.

Adaptive DML

Targets simpler treatment-effect structure

Most appealing when treatment-effect structure can stabilize ATE estimation.

Standard Calibrated DML

Broader inferential baseline

Better suited when broader inferential guarantees are the main priority.

Causal assumptions still apply

You still need the usual assumptions behind causal effect estimation, including no unmeasured confounding, consistency, and overlap.

Weak overlap may still matter

Adaptive structure can improve stability under weak overlap, but it does not solve zero-overlap problems.

The signal must be informative

Any gain depends on learning a treatment-effect pattern that is informative for the ATE.

Mode

Which mode is the default adaptive entry point?

calibrated_rlearner is the default adaptive entry point on this page. It is the mode that most directly estimates the ATE through a learned treatment-effect summary.

Estimator

Direct treatment-effect route

The calibrated R-learner learns a treatment-effect summary, calibrates it, and plugs it into the ATE estimator.

Alternative mode

What does plugin do?

The plugin mode calibrates the outcome regression directly instead of a treatment-effect summary.

Mode

plugin

Calibrates the outcome regression directly and uses that calibrated outcome-regression summary in the estimator.

Position

Secondary to the calibrated R-learner path

This page treats it as secondary to the calibrated R-learner path.
