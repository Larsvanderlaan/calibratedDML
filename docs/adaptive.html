Adaptive DML

Adaptive DML for binary-treatment ATE estimation.

Adaptive DML for the ATE works in a partially linear model, uses an estimated CATE as a one-dimensional summary of effect heterogeneity, calibrates along that summary, and debiases in the induced working model.

Overview How it works Modes
  • Binary treatment only
  • ATE estimated through a scalar CATE summary
  • Different inferential scope than standard calibrated DML

At A Glance

Scope Binary-treatment adaptive ATE estimation.
Main mode calibrated_rlearner uses the estimated CATE as the adaptive summary.
Alternative plugin uses the outcome regression as the summary instead.

What

What is the estimator?

The target on this page is the binary-treatment ATE. calibrated_rlearner is the main adaptive mode: it uses the estimated CATE, meaning how treatment effects vary across units, as a scalar summary of effect heterogeneity and targets the ATE through the induced one-dimensional working model.

Target

Average treatment effect

The target parameter on this page is the ATE, not a general collection of adaptive estimands.

Adaptive summary

Estimated CATE as a scalar reduction

The estimated CATE compresses the effect model to one dimension before calibration and debiasing.

Primary mode

calibrated_rlearner

This is the main adaptive path documented on this page.

How

How does it work?

In the main documented path, a partially linear R-learner setup separates baseline outcome prediction from treatment-effect learning, then calibrates and debiases the learned effect summary.

Step 1

Fit nuisances and a preliminary CATE

Estimate the outcome and treatment-assignment functions, then fit a preliminary CATE.

Step 2

Calibrate along the estimated CATE

Use the estimated CATE as a one-dimensional summary and calibrate along that summary.

Step 3

Debias and average to the ATE

Debias in the induced working model and average to estimate the ATE.

Why

Why use it?

The motivation is the overlap and weighting tradeoff for ATE estimation: fully nonparametric methods are flexible but can be unstable, while constant-effect models are stable but restrictive. Adaptive DML sits between those two regimes.

Fully nonparametric AIPW

Most flexible, strongest overlap demands

This route allows rich heterogeneity but typically needs the most overlap and can have the highest variance.

Constant-effect PLM

Most structured, least overlap-sensitive

This can be much more stable, but it can be wrong if the treatment effect is not constant.

Learned CATE model

Middle ground

Adaptive DML uses the learned CATE as a one-dimensional middle ground: more structured than the nonparametric route, less restrictive than a constant-effect model.

The adaptive estimator works through overlap in the learned one-dimensional CATE summary rather than through the full covariate space. When that summary is informative, this can yield a lower-variance alternative to the fully nonparametric route; in favorable cases, this is the super-efficiency phenomenon.

When

When is it useful?

Adaptive DML is mainly worth considering when overlap is too weak for reliable or precise fully nonparametric inference and the treatment-effect pattern may be simpler than the full outcome surface.

Weak overlap is the main use case

This page is most relevant when the fully nonparametric route is unstable because inverse-overlap weights are too variable.

It adapts to near-constant effects

Constant-effect models are contained in the adaptive working model, so the estimator adapts naturally when the CATE is close to constant.

Use cautiously

Inference is for the induced working model, not the broadest standard calibrated DML target.

Modes

Available adaptive modes

The package exposes two adaptive modes.

Primary mode

Alternative mode

plugin

Uses the outcome regression as the adaptive summary instead.
