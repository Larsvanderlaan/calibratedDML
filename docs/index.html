Doubly robust inference
via calibration.

Estimate average treatment effects after calibrating outcome predictions and inverse probability weights. Calibration improves their fit to the data and supports doubly robust inference: confidence intervals can remain valid if one nuisance function is estimated well enough, even when the other is estimated badly or slowly.

Why calibrate?

Double robustness
for inference.

A doubly robust point estimate can be consistent when only one nuisance estimator is consistent. Its usual confidence interval can still fail. Calibrating the nuisance estimates allows valid inference under weaker estimation requirements.
