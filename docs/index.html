Causal Inference And Econometrics

Calibrated debiased machine learning for causal effect inference.

Standard doubly robust estimators such as AIPW are doubly robust for point estimation, but valid confidence intervals usually still need both nuisance functions estimated sufficiently well. calibratedDML is built to change that: calibration extends double robustness to inference, so confidence intervals can remain valid when one nuisance is estimated sufficiently well, even if the other is slow or wrong.

Calibration

Calibration is why the package gives doubly robust inference

The package calibrates the nuisance functions after fitting and before debiasing. That extra step is what turns a standard doubly robust estimator into a calibrated one with weaker nuisance-rate requirements for inference.

In practice, calibration can also automatically stabilize extreme inverse weights and reduce variance, especially when overlap is limited; see Stabilized Inverse Probability Weighting via Isotonic Calibration. But this does not remove the need for population-level positivity or overlap assumptions in the theory.

Outcome Regression Calibration

Predictions align with observed outcomes

Calibration maps raw outcome predictions so units with similar predicted outcomes have observed outcomes on the right scale.

Propensity Calibration

Weights stabilize and balance improves

Calibration adjusts the propensity score scale so units within levels of estimated propensity behave more like balanced groups, which automatically dampens extreme inverse weights.

These calibration steps help with finite-sample bias and variance, and in the calibrated-DML theory they are the reason one sufficiently good nuisance can be enough for valid inference.
